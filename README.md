# Таблица Менделеева 🔬

Интерактивное приложение на Python (Tkinter) — периодическая система химических элементов.

## ✨ Возможности

- 📋 Отображение всех 118 элементов
- 🖱 Клик по элементу — карточка с информацией
- 🔍 Поиск по названию и символу
- 🎨 Цветовая кодировка по категориям
- 🖥 Полноэкранный режим
